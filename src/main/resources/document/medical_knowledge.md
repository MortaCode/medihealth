# 微医健康 · 医学知识库

> 本文档用于智能问诊系统的RAG（检索增强生成）知识检索。内容涵盖常见疾病、用药安全和健康生活三大板块。

---

## 一、常见疾病知识

### 1.1 感冒（急性上呼吸道感染）

**概述**：感冒是最常见的急性上呼吸道感染性疾病，全年均可发病，以冬春季为高发期。主要由病毒引起，以鼻病毒（Rhinovirus）最为常见，约占30%-50%，其次为冠状病毒、流感病毒、副流感病毒、呼吸道合胞病毒等。

**传播途径**：
- 飞沫传播：患者咳嗽、打喷嚏时喷出的飞沫中含有大量病毒。
- 接触传播：手接触被病毒污染的物品后，再触摸口、鼻、眼等黏膜部位。

**临床表现**：
- 早期症状（1-3天）：咽干、咽痒、打喷嚏、鼻塞、流清水样鼻涕。
- 中期症状（2-4天）：鼻涕变稠，可伴有咽痛、咳嗽、声音嘶哑。
- 全身症状：可有低热（通常不超过38.5℃）、轻度畏寒、头痛、全身酸痛、乏力。
- 病程：一般为5-7天，多数可自愈。如超过7天未缓解或症状加重，应及时就医。

**鉴别诊断**：
- 流感：起病急骤，高热（39-40℃），全身症状重，局部症状轻。
- 过敏性鼻炎：反复发作，鼻痒、阵发性打喷嚏、大量清水样鼻涕，与过敏原接触有关。
- 新冠肺炎（COVID-19）：发热、干咳、乏力为主要表现，部分患者以嗅觉味觉减退为首发症状。

**治疗原则**：
- 一般治疗：多休息、多饮水、保持室内通风、清淡饮食。
- 对症治疗：发热、头痛可选用对乙酰氨基酚或布洛芬（成人常规剂量，详见药品说明书）。鼻塞可用生理盐水喷鼻剂。
- 不推荐常规使用抗生素，除非有明确细菌感染证据（如黄脓涕>10天，血常规示白细胞及中性粒细胞升高）。
- 抗病毒药物：对于流感，发病48小时内使用奥司他韦可有效缩短病程。

**预防措施**：
- 勤洗手，使用肥皂或洗手液，采用七步洗手法。
- 保持社交距离，流感高发季避免去人群密集场所。
- 佩戴口罩，尤其在密闭公共空间。
- 每年接种流感疫苗是预防流感的有效手段。
- 增强体质：规律作息，均衡营养，适度锻炼，保持良好心态。

### 1.2 高血压

**定义**：在未使用降压药物的情况下，非同日3次测量诊室血压，收缩压≥140mmHg和/或舒张压≥90mmHg。根据血压水平可分为1级（轻度）、2级（中度）、3级（重度）。

**流行病学**：我国18岁及以上居民高血压患病率约为27.9%，患病人数约达2.45亿。知晓率、治疗率和控制率分别为51.6%、45.8%和16.8%，仍有较大提升空间。

**危险因素**：
- 不可改变因素：年龄增长、遗传因素、性别（男性风险高于女性直至女性绝经）。
- 可改变因素：高钠低钾饮食、超重和肥胖（BMI≥24）、过量饮酒、长期精神紧张、缺乏体力活动。

**常见症状**：
- 大多数患者起病缓慢，早期可无症状或仅有头晕、头胀、颈部僵硬等非特异性症状。
- 部分患者可有心悸、胸闷、乏力、视物模糊、鼻出血等表现。
- 长期未控制的高血压可导致靶器官损害：脑卒中、心肌梗死、心力衰竭、肾衰竭、视网膜病变等。

**诊断与监测**：
- 诊室血压测量是诊断的金标准，建议使用经认证的上臂式电子血压计。
- 家庭血压监测（HBPM）和动态血压监测（ABPM）有助于排除"白大衣高血压"和"隐蔽性高血压"。
- 测量前30分钟不吸烟、不饮咖啡，排空膀胱，安静休息5分钟。测量时手臂与心脏平齐。

**治疗与生活方式干预**：
- 低盐饮食：每日食盐摄入量<5g（约一个啤酒瓶盖的量），减少酱油、味精等含钠调味品。
- 控制体重：BMI控制在18.5-23.9之间，腰围男性<90cm，女性<85cm。
- 规律运动：每周至少150分钟中等强度有氧运动（如快走、慢跑、游泳、太极拳）。
- 戒烟限酒：彻底戒烟，避免二手烟。男性酒精摄入量<25g/日，女性<15g/日。
- 保持心理平衡：避免情绪大起大落，可通过冥想、深呼吸等方式减轻压力。

**药物治疗**：
- 常用降压药五大类：钙通道阻滞剂（CCB）、血管紧张素转化酶抑制剂（ACEI）、血管紧张素II受体拮抗剂（ARB）、利尿剂、β受体阻滞剂。
- 用药原则：小剂量起始、优先选择长效制剂、联合用药、个体化治疗。
- 需长期规律服药，不可自行停药或加减剂量。突然停药可导致血压反弹，诱发心脑血管事件。

### 1.3 糖尿病

**概述**：糖尿病是一组以慢性高血糖为特征的代谢性疾病，由胰岛素分泌和/或作用缺陷引起。长期高血糖可导致多系统损害。

**分型**：
- 1型糖尿病：胰岛β细胞破坏，胰岛素绝对缺乏，多见于青少年。
- 2型糖尿病：胰岛素抵抗伴胰岛素分泌相对不足，占糖尿病的90%以上，多见于中老年人。
- 妊娠期糖尿病（GDM）：妊娠期间发生的不同程度糖代谢异常。

**诊断标准**：
- 典型糖尿病症状（多饮、多尿、多食、体重下降）+ 任意时间血糖≥11.1mmol/L。
- 空腹血糖（FPG）≥7.0mmol/L（空腹状态指至少8小时未进食）。
- 口服葡萄糖耐量试验（OGTT）2小时血糖≥11.1mmol/L。
- 糖化血红蛋白（HbA1c）≥6.5%。

**管理目标（"五驾马车"）**：
- 饮食控制：控制总热量摄入，合理分配碳水化合物、蛋白质、脂肪比例。多食高纤维食物（全谷物、蔬菜），限制精制糖和饱和脂肪。
- 运动治疗：餐后1小时进行30分钟左右的有氧运动，注意防止低血糖。
- 药物治疗：口服降糖药（如二甲双胍、磺脲类、DPP-4抑制剂、SGLT-2抑制剂等）或胰岛素治疗。
- 血糖监测：定期自我监测血糖，每3-6个月检测糖化血红蛋白。
- 健康教育：学习糖尿病自我管理知识，提高治疗依从性。

**并发症**：
- 急性：糖尿病酮症酸中毒（DKA）、高渗高血糖状态（HHS）、低血糖（血糖<3.9mmol/L）。
- 慢性微血管病变：糖尿病视网膜病变（可致盲）、糖尿病肾病（可致肾衰竭）、糖尿病神经病变。
- 慢性大血管病变：冠心病、脑卒中、下肢动脉病变（可致足部坏疽甚至截肢）。

## 二、用药安全知识

### 2.1 合理用药基本原则

**五正确原则**：正确的患者、正确的药物、正确的剂量、正确的途径、正确的时间。

**安全用药注意事项**：
- 就医时主动告知医生过敏史（药物、食物）和正在服用的所有药物（包括处方药、非处方药、保健品）。
- 处方药须凭执业医师处方购买和使用，不可自行购买或借用他人药物。
- 服药前仔细阅读药品说明书，特别注意【适应症】【用法用量】【不良反应】【禁忌】【注意事项】。
- 严格按照医嘱或说明书规定的剂量和疗程用药，不擅自增减或停药。
- 儿童、孕妇、哺乳期妇女、老年人及肝肾功能不全者用药需特别谨慎，应在医生指导下进行。
- 服药期间禁止饮酒—酒精可能增强药物副作用或降低药效（如头孢类药物+酒精可致双硫仑样反应）。

### 2.2 常见药物的合理使用

**解热镇痛药**：
- 对乙酰氨基酚：成人常规剂量每次500mg，每日不超过2g。过量可致严重肝损伤。是孕产妇退热的首选药物。
- 布洛芬：兼具抗炎作用，成人常规剂量每次200-400mg。胃溃疡、严重肾功能不全者禁用。餐后服用可减少胃部不适。
- 注意：不要同时服用多种含有相同成分的复方感冒药，以免重复用药导致过量。

**抗生素**：
- 抗生素仅对细菌感染有效，对病毒性感染（如普通感冒）无效。
- 严格遵守抗生素使用指征，避免不必要的使用。
- 完成全程治疗，不可因症状好转而擅自停药。
- 注意观察过敏反应：皮疹、瘙痒等为常见表现，严重者可出现呼吸困难、休克（速发型过敏需立即就医）。

### 2.3 中药用药安全

- 中药不等于"无毒副作用"。部分中药（如何首乌、雷公藤、关木通等）具有明确的肝肾毒性。
- 中成药也需辨证论治，风寒感冒和风热感冒用药不同，不可混淆。
- 中西药合用时需注意间隔时间（一般间隔1-2小时），避免相互影响。
- 长期服用中药者应定期监测肝肾功能。

## 三、健康生活建议

### 3.1 合理膳食

- **食物多样，谷类为主**：每日摄入食物种类不少于12种，每周不少于25种。
- **多吃蔬果**：每天摄入蔬菜300-500g，其中深色蔬菜占一半以上。水果200-350g。
- **适量摄入优质蛋白**：优先选择鱼和禽肉，少吃肥肉、烟熏和腌制肉制品。
- **控油限盐**：每人每天烹饪油25-30g，食盐<5g。
- **足量饮水**：成人每天饮水1500-1700ml，首选白开水，少量多次饮用。

### 3.2 科学运动

- **频率**：每周至少5天，最好每天坚持。
- **强度**：中等强度（运动时可以说话但不能唱歌的程度）。
- **时长**：每次30-60分钟。
- **类型**：有氧运动（快走、慢跑、游泳、骑车）+ 力量训练（深蹲、俯卧撑、弹力带练习）+ 柔韧性训练（拉伸、瑜伽）。
- **注意事项**：运动前热身5-10分钟，运动后放松拉伸；慢性病患者运动前应咨询医生。

### 3.3 心理健康

- 保持乐观积极的心态，学会接纳和管理负面情绪。
- 建立健康的社交关系，与家人朋友保持良好沟通。
- 保证充足睡眠：成人每晚7-9小时，规律作息时间。
- 学会压力管理：深呼吸、正念冥想、听音乐、阅读、户外散步等都是有效的减压方式。
- 当出现持续（>2周）的情绪低落、兴趣减退、睡眠障碍等症状时，应及时寻求专业心理帮助。

### 3.4 定期体检

- 成人建议每年进行1次健康体检。
- 重点关注：血压、血糖、血脂、肝功能、肾功能、体重指数（BMI）、腰围。
- 40岁以上人群建议增加：胃肠镜检查（每3-5年）、低剂量螺旋CT（肺癌筛查，吸烟者）、骨密度检测（更年期后女性）。
- 女性应定期进行乳腺和宫颈癌筛查；男性应关注前列腺健康。
